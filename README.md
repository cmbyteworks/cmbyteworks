## About

I’m a maker and developer working across software, electronics, and hands-on DIY. My projects bring together Android and Linux apps, ESP32 and Raspberry Pi devices, automation, and 3D-printed parts.

## Featured project

### PrintPilot

A native Android client for OctoPrint, built to make 3D printer control and monitoring accessible from Android. The repository is currently private while the project is in development; a public link will be added when it is released.

## Workshop

I design and print functional parts on an **Ender 3 V3 SE**, alongside enclosures and practical workshop projects. I also build personal DIY and automation projects that connect software with everyday hardware.
